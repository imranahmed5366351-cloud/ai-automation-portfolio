# AI Career Roadmap Generator

## Overview
I built an AI-powered Career Roadmap Generator using n8n. It helps users explore career paths and generate personalized learning roadmaps based on their interests and goals.

## Problem
People often struggle to decide what skills to learn and what steps to take to reach a career goal. This project explores using AI to make career planning easier.

## Tools Used
- n8n
- AI / LLM
- Workflow Automation
- Prompt Engineering

## How It Works
1. The user provides career interests or goals.
2. The workflow processes the information.
3. AI generates a career roadmap.
4. The roadmap provides suggested skills and learning steps.
