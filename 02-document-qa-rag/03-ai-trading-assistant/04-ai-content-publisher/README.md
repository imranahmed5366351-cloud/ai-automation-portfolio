# AI Content Idea to Multi-Platform Publisher

## Overview
I built an AI-powered content workflow using n8n that transforms content ideas into platform-specific content drafts for multiple social media platforms.

## Problem
Creating content for multiple platforms takes time. Each platform requires a different format, tone, and style. This workflow explores automating the content creation process.

## Tools Used
- n8n
- AI / LLM
- Workflow Automation
- APIs

## How It Works
1. A content idea is submitted to the workflow.
2. AI processes the idea.
3. Content is generated for different platforms.
4. The generated content is prepared for publishing.
