# AI Trading Assistant

## Overview
I built an AI-powered Trading Assistant using n8n, Pinecone, and Retrieval-Augmented Generation (RAG). The project combines AI and information retrieval to assist users with trading-related research and information.

## Problem
Trading-related information can be spread across different sources. This project explores how AI and RAG can help organize and retrieve relevant information through an automated workflow.

## Tools Used
- n8n
- Pinecone
- RAG (Retrieval-Augmented Generation)
- AI / LLM
- Workflow Automation

## How It Works
1. Relevant information is processed and stored.
2. Pinecone is used for information retrieval.
3. The AI workflow receives user queries.
4. Relevant context is retrieved.
5. AI generates a response based on the available context.

## What I Learned
- Building AI-powered workflows
- Working with Pinecone
- Implementing RAG concepts
- Connecting AI tools with automation
- Designing multi-step workflows
