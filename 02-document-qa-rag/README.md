# Document Q&A System (RAG)

## Overview
I built a document question-answering system using n8n and Pinecone. It uses Retrieval-Augmented Generation (RAG) to help users find information from documents.

## Problem
Searching through long documents manually can take a lot of time. This project helps users retrieve relevant information and get answers to questions about their documents.

## Tools Used
- n8n
- Pinecone
- Retrieval-Augmented Generation (RAG)
- AI / LLM
- Vector Database

## How It Works
1. Documents are processed for information retrieval.
2. Document data is stored in Pinecone.
3. A user asks a question.
4. The system searches for relevant information.
5. Retrieved information is used to generate an answer.

- Building document-based AI workflows
